# 本机验证记录

## v0.3 上下文提示 · 2026-09-22

- 收藏模型增加可选的来源应用、来源 bundle ID 和复制时间字段；旧版 `library.json` 缺少这些字段时仍可读取。
- 主动收藏会记录来源上下文；内容与现有收藏相似度达到本地阈值时，编辑窗口显示旧收藏入口，不自动合并或覆盖原文。
- 自动发现建议会带上复制来源和时间，保存后可在收藏详情中查看；未增加网络请求。
- `action_item` 判断现在保存为「任务」分类，卡片按钮显示「加入待办」，可用左侧分类筛选；仍由用户点击保存，不创建系统通知。
- 自动发现卡片的标题和说明可在保存前编辑；Ctrl+Option+Space 使用独立快速搜索面板，再次按下可关闭，结果支持方向键选择和回车复制并返回前台应用。
- 右上角 JEV 设置入口支持修改 API Key、Decisions API URL 和模型；配置保存到 `.local/recall/settings.json`（权限 0600），空 API Key 会回退到 `.env`，保存后立即应用到语义查找和自动发现。
- 构建通过；核心 20 / 20、原生收藏 9 / 9、自动发现 31 / 31 通过。

## v0.2 自动发现 · 2026-09-21

- 新增 31 项自动发现检查全部通过，使用独立测试剪贴板。覆盖默认关闭、不追读已有剪贴板、本地凭据/私密标记排除、已有收藏排除、按原文保存且仅执行一次、90 秒冷却、10 分钟最多三次、忽略去重、暂停/恢复、关闭后的迟到结果丢弃、快速连续复制合并。
- 原有 20 项核心测试、9 项原生收藏/复制测试重新运行并通过。由于访问系统剪贴板服务受沙箱限制，原生测试使用获准运行的测试进程；不读写用户通用剪贴板。
- 最终真实判断 11 / 11 符合开发预设，API 端到端耗时 560–954 ms，中位数 719 ms，合计 $0.00038724。不包含剪贴板轮询、等待文本稳定和绘制卡片的时间。
- 这些人工示例用于调整过判断标准，不能当成独立评测或对用户真实复制内容的准确率承诺。
- 第一轮笼统询问“长期有用吗”过于保守，10 个案例仅 4 个符合预设，记录保存在 `artifacts/discovery-live-initial.json`。最终改为判断具体可回看的信息，不预测用户个人偏好；类型分布的不确定性不再冒充记录价值的不确定性。普通一次性礼貌回复改为跳过，单独新增明确的“常用回复模板”案例，两者分别验证。
- 最终记录：`artifacts/discovery-live.json`。卡片外观：`artifacts/discovery-card.png`，使用示例文本，预览期间自动发现关闭。
- 原生提醒窗口焦点检查通过：`frontmostUnchanged=true`。卡片显示不切换当前前台应用；点击标题或说明输入框时才接收键盘焦点。

## 原生界面

已编译 `build/Recall.app` 并通过本机临时签名，实际启动原生窗口，使用仅含示例的预览模式生成 `artifacts/recall-preview.png` 并检查排版。预览不读取系统剪贴板、不写收藏、不调用模型。

首次构建发现本机 Command Line Tools 同时遗留两份 SwiftBridging 模块定义。`scripts/swiftc-local.sh` 通过编译器 VFS overlay 隐藏重复项，并显式选择本机 SDK；仅写入项目 `.build`，没有修改系统 SDK 或工具链。[Swift 官方介绍 VFS overlay](https://www.swift.org/documentation/articles/wrapping-c-cpp-library-in-swift.html)。
