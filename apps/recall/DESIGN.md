# 随手贴 · Recall

给经常复制命令、链接和回复的人用的 macOS 小抽屉。唯一主动作：描述用途，取回自己存过的原文。

采用原生 SwiftUI + AppKit：左侧收藏列表，右侧完整原文；搜索框贯穿上方。主窗口 1000×700，可缩放。全局 Ctrl+Option+Space 呼出，Ctrl+Option+C 主动收藏剪贴板。复制后可回到原应用，用户按 Cmd+V 粘贴。

视觉方向：薄荷灰 #EDF3F2 背景，纸白 #FFFFFF 原文，墨绿 #17493E 主动作，石墨 #253B37 文本，灰绿 #758A83 辅助，珊瑚 #C97254 低置信提示。标题用系统圆体，正文用系统无衬线，命令和数据用等宽字体。标志是两张互相错开的文本便签，表现“存下、再取回”。避免仪表盘和营销大标题；让搜索和原文本身占据界面。

收藏始终由用户点击保存。默认手动添加；v0.3 提供可选的自动发现模式、可编辑提醒卡片、复制来源记录、相似收藏提示和任务分类。自动发现读取新复制文本并通过 JEV 判断是否值得提醒，采用不激活应用的角落卡片；用户点击输入框时卡片才接收键盘焦点。首次开启前默认关闭，之后记住开关选择。卡片使用白色便签底和墨绿“记下来/加入待办”按钮，保存后显示短暂确认，18 秒超时，90 秒冷却，每 10 分钟最多 3 次，支持暂停 1 小时和按类别静音 24 小时。Ctrl+Option+Space 呼出独立的快速搜索面板，复制结果后返回之前的应用。窗口右上角齿轮提供 JEV 设置入口，保存后即时替换语义查找和自动发现使用的 API 配置。

每条已存片段可设为“仅本地”，参与关键词查找但从语义请求中排除。语义请求发送检索词、标题、用途提示及前 240 字，原文始终完整保存在本地。语义模式在输入停止约 350 毫秒后自动更新结果，继续输入会取消上一轮请求；也可按回车立即查找。当前会话重复查询优先使用短期内存缓存，收藏或 JEV 设置变化时清空缓存。没有匹配时明确显示未找到。JEV 只选片段，不改写原文。示例地址仅用于演示，标记为示例。

第一版限 64 条收藏，使全部候选可在一轮 JEV 请求中比较。原文最多 8000 字。对长片段末尾内容的语义搜索应通过用途提示补充；完整原文可用本地关键词搜索。
